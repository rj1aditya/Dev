🧠 What is CASE in SQL?

CASE = IF-ELSE logic inside SQL

⸻

🔹 Basic Syntax

CASE 
    WHEN condition THEN value
    WHEN condition THEN value
    ELSE value
END


⸻

🔍 Simple Example

SELECT name,
CASE 
    WHEN salary > 100000 THEN 'High'
    ELSE 'Low'
END as category
FROM employees;

👉 Like:

if salary > 100000 → High  
else → Low


⸻

🔥 Where CASE is used (important for you)

1. Inside SELECT (for labeling)

2. Inside COUNT / SUM (VERY IMPORTANT for Q2)

⸻

🧠 The Key Trick (This is what you saw in Q2)

COUNT(CASE WHEN condition THEN 1 END)


⸻

🔍 What this does

👉 For each row:
	•	if condition TRUE → return 1
	•	if FALSE → return NULL

👉 And:

COUNT() ignores NULL


⸻

⚡ So effectively:

“Count only rows where condition is true”

⸻

🧪 Example

orders

order_id
50
120
130


⸻


SELECT COUNT(CASE WHEN order_id > 100 THEN 1 END)
FROM orders;


⸻

Evaluation:

order_id	CASE result
50	NULL
120	1
130	1

👉 COUNT = 2

⸻

🔥 Why we used CASE in Q2

Q2 required:

“users who have NO orders ≥ 100”

⸻

So we wrote:

COUNT(CASE WHEN o.order_id >= 100 THEN 1 END) = 0


⸻

🧠 Meaning:

👉 “Count how many bad orders exist (≥100)”
👉 If count = 0 → user is valid

⸻

⚡ Alternative thinking

CASE helps you:
	•	selectively count
	•	selectively sum
	•	selectively evaluate

⸻

👊 Key Patterns (must remember)

✅ Count conditionally

COUNT(CASE WHEN condition THEN 1 END)


⸻

✅ Sum conditionally

SUM(CASE WHEN condition THEN amount ELSE 0 END)


⸻

🧠 Mental Model

CASE = “convert condition into a value”

⸻

🔥 Mini Practice (Do this)
